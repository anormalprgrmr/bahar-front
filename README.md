# بهار — فروشگاه آنلاین آرایشی و مراقبت پوست

فروشگاه آنلاین محصولات آرایشی و مراقبت پوست با رابط کاربری فارسی.

## اجرا

```bash
npm install
npm run dev
```

## ساختار پروژه

```
src/
├── app/              # تنظیمات اپلیکیشن و مسیریابی
├── components/       # کامپوننت‌های قابل استفاده مجدد
│   ├── auth/         # محافظت از مسیرها
│   ├── layout/       # هدر، فوتر، لایه اصلی
│   ├── products/     # کارت و گرید محصول
│   └── ui/           # اجزای رابط کاربری
├── contexts/         # احراز هویت و سبد خرید
├── features/         # بخش‌های صفحه اصلی و جزئیات محصول
├── pages/            # صفحات (خانه، ورود، پروفایل، سبد، پرداخت)
├── services/         # لایه سرویس (mock + آماده اتصال به API)
├── mocks/            # داده‌های آزمایشی
├── hooks/            # هوک‌های سفارشی
├── utils/            # توابع کمکی
├── types/            # تعریف تایپ‌ها
└── styles/           # استایل‌های سراسری
```

## جریان کاربری (فعلاً mock در localStorage)

- ثبت‌نام / ورود
- تکمیل پروفایل (آدرس، تلفن، …)
- افزودن محصول به سبد
- ثبت سفارش از سبد و پرداخت آزمایشی
- مشاهده سفارش‌ها در حساب کاربری

## اتصال به بک‌اند

پس از دریافت فایل OpenAPI، متغیر `VITE_API_BASE_URL` را در `.env` تنظیم کنید. سرویس‌های موجود در `src/services/` به‌تدریج به API واقعی متصل می‌شوند.
