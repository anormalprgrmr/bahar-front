# بهار — فروشگاه آنلاین آرایشی و مراقبت پوست

فروشگاه آنلاین محصولات آرایشی و مراقبت پوست با رابط کاربری فارسی.

## اجرا

```bash
npm install
npm run dev
```

## ساختار پروژه

```
src/
├── app/              # تنظیمات اپلیکیشن و مسیریابی
├── components/       # کامپوننت‌های قابل استفاده مجدد
│   ├── layout/       # هدر، فوتر، لایه اصلی
│   ├── products/     # کارت و گرید محصول
│   └── ui/           # اجزای رابط کاربری
├── features/         # بخش‌های صفحه اصلی
├── pages/            # صفحات
├── services/         # لایه سرویس (آماده اتصال به API)
├── mocks/            # داده‌های آزمایشی
├── hooks/            # هوک‌های سفارشی
├── utils/            # توابع کمکی
├── types/            # تعریف تایپ‌ها
└── styles/           # استایل‌های سراسری
```

## اتصال به بک‌اند

پس از دریافت فایل OpenAPI، متغیر `VITE_API_BASE_URL` را در `.env` تنظیم کنید. سرویس‌های موجود در `src/services/products/productService.js` به‌صورت خودکار از API استفاده خواهند کرد.

## اسکریپت‌ها
